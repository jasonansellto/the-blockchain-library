# The Blockchain Library v2.3.0 — Coverage Intelligence

v2.3.0 adds a structured editorial-intelligence layer around the canonical Knowledge Engine.

## Highlights
- coverage analysis across 3,545 canonical objects;
- context-aware scoring;
- graph-centrality and improvement-priority analysis;
- coverage matrix and category heatmap;
- missing-concept and unresolved-relationship review;
- release snapshots and editorial tasks;
- JSON/CSV exports for future GitHub integration.

## Known limitation
The initial v2.3.0 scoring pass exposed resolution issues for several supporting-resource dimensions. The canonical knowledge remains intact. v2.3.1 is dedicated to Coverage Resolution & Diagnostics and will establish the corrected scoring baseline.
