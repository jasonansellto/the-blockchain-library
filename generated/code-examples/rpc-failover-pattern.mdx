# RPC Failover Pattern

Try multiple RPC endpoints in sequence when the primary endpoint is unavailable.

```javascript
for (const url of rpcUrls) { try { return await callRpc(url, payload); } catch {} }
```

<Warning>
Examples are intentionally minimal. Production code should add input validation, error handling, network checks, security controls, and application-specific safeguards.
</Warning>
