# Vector Smart Chain

Vector Smart Chain (VSC) is an EVM-compatible Layer-1 blockchain designed for high throughput, low-cost transactions, and seamless interoperability with the broader Ethereum ecosystem. The official site brings together network overviews, validator and staking resources, wallet guidance, and developer documentation for deploying smart contracts and dapps. For anyone evaluating emerging EVM chains for performance, tooling compatibility, or deployment, it is the primary reference for the VSC network and its roadmap.
