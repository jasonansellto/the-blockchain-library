# Polkadot: Vision for a Heterogeneous Multi-chain Framework

This 2016 whitepaper outlines the vision for Polkadot, a novel blockchain architecture designed to address the limitations of single, monolithic blockchains by

## Abstract

This 2016 whitepaper outlines the vision for Polkadot, a novel blockchain architecture designed to address the limitations of single, monolithic blockchains by enabling interoperability between diverse and specialized chains. The core proposal is a 'heterogeneous multi-chain' framework where a central Relay Chain coordinates a network of independent, yet connected, parachains. Each parachain can have its own unique logic, tokenomics, and governance, fostering innovation and scalability. The system employs a shared security model where validators on the Relay Chain stake their tokens to secure all connected parachains, eliminating the need for each parachain to establish its own validator set and consensus mechanism from scratch. This approach aims to create a more scalable, flexible, and interconnected blockchain ecosystem, moving beyond the isolated nature of early blockchain designs and paving the way for a multi-chain future.

**Authors:** Gavin Wood

**Publication:** Project Whitepaper

**Publication date:** 2016-01-01

## Key findings

- Polkadot proposes a heterogeneous multi-chain framework to overcome blockchain scalability and interoperability issues.
- A central Relay Chain coordinates specialized parachains, each with unique functionalities.
- Shared security, facilitated by Relay Chain validators, enhances the security of individual parachains.
- The architecture aims to enable seamless communication and asset transfer between different blockchains.
