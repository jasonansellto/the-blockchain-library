# Optimizing internet of things security through blockchain enabled software defined networking

This research focuses on the optimization of IoT security by proposing an architecture that integrates blockchain technology with software-defined networking (S

## Abstract

This research focuses on the optimization of IoT security by proposing an architecture that integrates blockchain technology with software-defined networking (SDN). The authors address the escalating security risks in massive IoT networks, where centralized SDN controllers can become vulnerable bottlenecks or targets for malicious actors. By implementing a blockchain-enabled decentralized controller architecture, the study demonstrates how network policies can be stored immutably and verified across a distributed environment. The methodology involves an experimental evaluation of network security, throughput, and latency in a simulated IoT environment, comparing the proposed hybrid framework against traditional centralized SDN setups. The results suggest that the combination of blockchain's trust guarantees and SDN's dynamic flow management significantly enhances network resilience against distributed denial-of-service (DDoS) attacks. The paper contributes a novel approach to securing large-scale network infrastructures by leveraging the decentralized nature of distributed ledgers to enforce robust security policies.

**Authors:** M. A. Khan, S. S. Kanhere

**Publication:** Academic Paper

**Publication date:** 2025-01-01

## Key findings

- Blockchain integration eliminates the single point of failure within centralized SDN controller architectures.
- Decentralized network policies increase resilience against sophisticated DDoS attacks in IoT ecosystems.
- Hybrid blockchain-SDN models effectively balance security requirements with high-performance networking needs.
- Automated security auditing is facilitated through the immutable nature of ledger-based policy enforcement.
