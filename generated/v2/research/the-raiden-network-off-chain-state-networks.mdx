# The Raiden Network: Off-chain State Networks

The Raiden Network whitepaper presents an off-chain scaling solution for the Ethereum blockchain, focusing on fast, low-cost, and private token transfers. Model

## Abstract

The Raiden Network whitepaper presents an off-chain scaling solution for the Ethereum blockchain, focusing on fast, low-cost, and private token transfers. Modeled after the Bitcoin Lightning Network, Raiden facilitates the creation of state channels where users can perform an unlimited number of transactions off-chain, with only the final balance settled on the Ethereum blockchain. The paper details the protocol for channel opening, payment transfers, and closing, emphasizing the role of 'mediator nodes' to facilitate multi-hop payments. By minimizing on-chain interaction, Raiden offers a significant reduction in gas fees and latency for Ethereum-based applications. This work represents a major milestone in the early development of Layer 2 solutions for Ethereum, illustrating how state channel networks can provide a scalable backbone for near-instant value transfer between accounts, contracts, and decentralized systems.

**Authors:** Heiko Hees

**Publication:** Project Whitepaper

**Publication date:** 2017-01-01

## Key findings

- Proposed a state channel network for Ethereum-based tokens.
- Reduced latency and transaction costs for token transfers.
- Enabled private, off-chain multi-hop transactions.
- Established a model for off-chain settlement on Ethereum.
