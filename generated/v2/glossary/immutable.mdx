# Immutable

Immutability describes a state or object that is incapable of being changed or altered once it has been recorded into the blockchain. In a cryptographic ledger, immutability is achieved by linking blocks of data through hashes, where each block contains the cryptographic fingerprint of the previous one. If a bad actor attempts to modify past transaction data, the hash of that block changes, invalidating all subsequent blocks in the chain, making tampering computationally impractical and instantly detectable by the network.

## Definition

Immutability describes a state or object that is incapable of being changed or altered once it has been recorded into the blockchain. In a cryptographic ledger, immutability is achieved by linking blocks of data through hashes, where each block contains the cryptographic fingerprint of the previous one. If a bad actor attempts to modify past transaction data, the hash of that block changes, invalidating all subsequent blocks in the chain, making tampering computationally impractical and instantly detectable by the network.

## Simple explanation

Think of a stone tablet where information is chiseled into the rock. Once you finish writing, you cannot go back and use an eraser to change the words without breaking the stone. In the digital world, blockchain does this using complex math. Once a transaction is saved on the chain, it is frozen forever, and no one—not even the creators—can go back and change what happened in the past.

## Why it matters

Immutability is critical for building systems where auditability and permanence are required, such as financial ledgers or digital property ownership. It prevents censorship and fraud by ensuring that the history of an asset cannot be retroactively rewritten by powerful entities.

## How it works

Data is hashed using cryptographic functions, creating a unique digital signature for that specific dataset. Each new block includes the hash of the preceding block, creating a linked chain of dependency. To alter a single piece of data, an attacker would need to recalculate every subsequent hash in the chain across the majority of network nodes simultaneously, which is mathematically impossible in a large, secure network.

## Real-world example

The Bitcoin blockchain is the premier example of an immutable ledger, where transactions recorded over a decade ago remain permanently fixed and verified.

## Advantages

- Ensures long-term data integrity
- Prevents fraudulent retroactive changes
- Provides an unalterable audit trail
- Builds trust in decentralized systems

## Limitations

- Prevents correction of genuine errors or bugs
- High barrier to removing illegal content or sensitive data
- Increased storage requirements over time

## Common misconceptions

- Some believe that because blockchain is immutable, it is impossible for software to have bugs or errors.
- People often mistake immutability for privacy, though the data is often visible to everyone on the public ledger.
