# Hard Fork

A hard fork is a radical change to a blockchain's protocol that makes previously invalid blocks and transactions valid, or vice versa, requiring all nodes or users to upgrade to the latest version of the protocol software. Because the new rules are incompatible with the old ones, the network splits into two separate chains: the original chain and the new, upgraded chain. This event permanently diverged the blockchain's history, effectively creating a new version of the cryptocurrency while leaving the legacy version behind.

## Definition

A hard fork is a radical change to a blockchain's protocol that makes previously invalid blocks and transactions valid, or vice versa, requiring all nodes or users to upgrade to the latest version of the protocol software. Because the new rules are incompatible with the old ones, the network splits into two separate chains: the original chain and the new, upgraded chain. This event permanently diverged the blockchain's history, effectively creating a new version of the cryptocurrency while leaving the legacy version behind.

## Simple explanation

Imagine a video game where a group of players disagrees on the rules. A hard fork is like splitting the game into two different versions: one group keeps the old rules, and the other starts a brand new game with new rules. If you want to play the new version, you have to download the update. Because the two games are now totally different, someone holding an item in the old game won't automatically have it in the new one unless the developers give it to them.

## Why it matters

Hard forks are essential for major software upgrades, security fixes, or resolving fundamental governance disputes within a community. They allow blockchain networks to evolve and pivot, though they often cause community fragmentation and market volatility.

## How it works

A hard fork occurs when the underlying codebase is modified, introducing new consensus rules that nodes running older software will reject. When miners or validators begin producing blocks following the new rules, the blockchain diverges from the legacy chain. Nodes must manually update their client software to follow the new ruleset, as the old version cannot process the new chain's data.

## Real-world example

The 2017 creation of Bitcoin Cash from the Bitcoin blockchain due to disagreements regarding block size limits.

## Advantages

- Enables critical software upgrades
- Resolves governance disputes
- Allows for network experimentation

## Limitations

- Causes community division
- Increases network security risks
- Confuses market participants

## Common misconceptions

- People often think a hard fork always creates a new coin, but it is actually a protocol update that might not result in a split if everyone agrees. Some believe it is a bug, when it is actually a deliberate feature of decentralized governance.
