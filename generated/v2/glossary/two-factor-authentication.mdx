# Two-Factor Authentication

Two-Factor Authentication (2FA) is a security process that requires users to provide two different authentication factors to verify their identity before gaining access to an account or system. These factors typically include something the user knows (password), something the user has (hardware token or mobile app), or something the user is (biometrics). In the context of cybersecurity and blockchain, 2FA acts as a critical secondary layer of defense, ensuring that even if a primary password is compromised, the account remains protected against unauthorized access.

## Definition

Two-Factor Authentication (2FA) is a security process that requires users to provide two different authentication factors to verify their identity before gaining access to an account or system. These factors typically include something the user knows (password), something the user has (hardware token or mobile app), or something the user is (biometrics). In the context of cybersecurity and blockchain, 2FA acts as a critical secondary layer of defense, ensuring that even if a primary password is compromised, the account remains protected against unauthorized access.

## Simple explanation

Imagine your bank account requires a key to open the door, but you also need a secret code sent to your phone to actually enter. That is 2FA. It means if someone steals your password (the key), they still can't get in because they don't have your phone (the code). It’s like having two locks on your front door instead of one, making it much harder for someone to break in.

## Why it matters

In crypto, 2FA is the first line of defense against account takeovers on centralized exchanges. Since transactions on blockchain networks are often irreversible, implementing 2FA is a non-negotiable best practice for protecting digital assets from theft and unauthorized trade execution.

## How it works

When a user logs in, the system validates the primary password. After successful verification, the system prompts the user for a second factor, such as a Time-based One-Time Password (TOTP) generated by an app like Google Authenticator or a FIDO2 hardware security key. The server validates this second factor against a pre-shared secret or cryptographic challenge; if both factors match, access is granted.

## Real-world example

Major crypto exchanges like Coinbase and Binance require users to enable 2FA via apps or physical YubiKeys to permit withdrawals, adding a vital layer of security beyond just the account password.

## Advantages

- Drastically reduces risk of account takeovers
- Provides security even if password is leaked
- Low cost and easy to implement for users

## Limitations

- SMS-based 2FA is vulnerable to SIM swapping
- Loss of access to the 2FA device can lock accounts
- Requires users to manage additional security steps

## Common misconceptions

- Users often think all 2FA is equally secure, but SMS-based verification is significantly less secure than app-based or hardware-based tokens.
- Some believe 2FA makes an account unhackable, but sophisticated phishing attacks can sometimes bypass it.
