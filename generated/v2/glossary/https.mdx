# HTTPS

Hypertext Transfer Protocol Secure (HTTPS) is the secure version of HTTP, the primary protocol used to send data between a web browser and a website. HTTPS encrypts the communication between the client and the server using Transport Layer Security (TLS) or its predecessor, Secure Sockets Layer (SSL). This ensures that data, such as login credentials, personal information, or transaction details, cannot be intercepted, read, or modified by unauthorized third parties during transit, thereby establishing a secure and authenticated connection for web interactions.

## Definition

Hypertext Transfer Protocol Secure (HTTPS) is the secure version of HTTP, the primary protocol used to send data between a web browser and a website. HTTPS encrypts the communication between the client and the server using Transport Layer Security (TLS) or its predecessor, Secure Sockets Layer (SSL). This ensures that data, such as login credentials, personal information, or transaction details, cannot be intercepted, read, or modified by unauthorized third parties during transit, thereby establishing a secure and authenticated connection for web interactions.

## Simple explanation

Think of HTTP like sending a postcard through the mail where anyone can read it. HTTPS is like putting that postcard inside a locked, armored briefcase that only the intended recipient has the key to open. It ensures that the messages you send to a website stay private and safe from prying eyes while they travel across the internet.

## Why it matters

In the blockchain ecosystem, HTTPS is the first line of defense for web-based wallets and decentralized application (dApp) interfaces. It prevents man-in-the-middle attacks that could otherwise redirect users to malicious sites or steal private keys before they are encrypted by the blockchain protocols.

## How it works

HTTPS works by layering HTTP over an encrypted connection provided by the TLS/SSL protocol. When a browser connects to a server, the server presents a digital certificate verified by a Certificate Authority to prove its identity. Once the connection is verified, the client and server perform a 'handshake' to negotiate symmetric encryption keys for the session, ensuring all subsequent data packets are encrypted.

## Real-world example

Every legitimate blockchain block explorer, such as Etherscan or Blockchain.com, uses HTTPS to ensure that when you search for transaction details or wallet balances, the data you view has not been tampered with by an attacker.

## Advantages

- Encrypts data during transit
- Provides authentication of website identity
- Prevents man-in-the-middle attacks
- Increases user trust and SEO ranking

## Limitations

- Does not protect data stored on the server
- Cannot prevent phishing on malicious websites
- Adds slight latency due to encryption overhead

## Common misconceptions

- Many people believe HTTPS means a website is inherently safe and scam-free.
- It is often wrongly assumed that HTTPS protects the privacy of the metadata about your visit.
