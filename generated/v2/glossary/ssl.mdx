# SSL

Secure Sockets Layer (SSL) is a cryptographic protocol designed to provide security for communications over a computer network. Although officially deprecated in favor of Transport Layer Security (TLS), the term remains in common parlance. SSL operates by establishing an encrypted link between a server and a client—typically a web server and a browser—ensuring that all data passed between them remains private and integral. It utilizes public-key cryptography to verify the identity of the server and establish a secure session.

## Definition

Secure Sockets Layer (SSL) is a cryptographic protocol designed to provide security for communications over a computer network. Although officially deprecated in favor of Transport Layer Security (TLS), the term remains in common parlance. SSL operates by establishing an encrypted link between a server and a client—typically a web server and a browser—ensuring that all data passed between them remains private and integral. It utilizes public-key cryptography to verify the identity of the server and establish a secure session.

## Simple explanation

Imagine you are talking to your bank through a private, soundproof tube. SSL is the technology that creates that 'tube' for your computer. It scrambles your information into a secret code before it leaves your device, so that if someone tries to eavesdrop, they will only see unreadable nonsense instead of your passwords or private data.

## Why it matters

SSL technology is fundamental to protecting the integrity of decentralized finance (DeFi) platforms and exchange portals. By preventing data modification during transmission, it ensures that transactions requested by the user reach the node or smart contract exactly as intended without interference.

## How it works

SSL uses a public-key infrastructure (PKI) involving a private key and a public key. The server holds the private key, while the public key is provided to the client via a digital certificate. During the handshake process, the client encrypts data with the public key, which only the server's private key can decrypt, thereby securing the communication channel.

## Real-world example

Crypto exchanges like Coinbase or Kraken use SSL/TLS certificates to secure user logins and trade execution pages, ensuring that sensitive account information is never exposed to attackers on the public internet.

## Advantages

- Ensures data integrity during transit
- Encrypts sensitive user communication
- Builds foundational trust for web services
- Authenticates the server's public identity

## Limitations

- Outdated versions are vulnerable to exploits
- Requires ongoing renewal of digital certificates
- Performance overhead from cryptographic processing

## Common misconceptions

- Users frequently think SSL is synonymous with TLS, even though SSL is technically a legacy protocol.
- It is a mistake to believe that an SSL certificate covers a website against all cyber threats.
