# MFA

Multi-Factor Authentication (MFA) is a security mechanism that requires users to provide two or more verification factors to gain access to a resource, such as a cryptocurrency exchange account. These factors typically include something the user knows (password), something the user has (hardware token or smartphone app), and something the user is (biometrics). MFA adds a critical layer of defense, ensuring that even if a password is stolen, the account remains protected from unauthorized access.

## Definition

Multi-Factor Authentication (MFA) is a security mechanism that requires users to provide two or more verification factors to gain access to a resource, such as a cryptocurrency exchange account. These factors typically include something the user knows (password), something the user has (hardware token or smartphone app), and something the user is (biometrics). MFA adds a critical layer of defense, ensuring that even if a password is stolen, the account remains protected from unauthorized access.

## Simple explanation

Think of MFA like a vault that needs both a physical key and a secret code to open. Even if a thief steals your key, they still cannot open the vault because they don't know the code. Using your phone to approve a login is like having a digital 'second key' that only you can use.

## Why it matters

MFA is the single most effective way to prevent unauthorized access to centralized crypto exchanges and wallet interfaces. Given the irreversible nature of blockchain transactions, MFA serves as the last line of defense against compromised credentials.

## How it works

After entering a username and password, the system triggers a second challenge. This might be a Time-based One-Time Password (TOTP) from an app like Google Authenticator or a hardware-based security key (FIDO2). Once the correct code is provided, the authentication server verifies the token against a shared secret or public key and grants account access.

## Real-world example

Using a YubiKey or the Google Authenticator app to secure a Binance or Coinbase account login session.

## Advantages

- Drastically reduces account takeover risk
- Provides protection if passwords are leaked
- Easily integrates with existing login flows

## Limitations

- Vulnerable to sophisticated phishing attacks
- Loss of physical token can lock users out
- Some methods rely on insecure SMS protocols

## Common misconceptions

- People often believe that SMS-based MFA is perfectly secure, when it is actually vulnerable to SIM-swapping attacks. Many users think setting up MFA makes their account unhackable, ignoring that phishing can still compromise the session.
