# Address

In blockchain, an address is a unique identifier derived from a public cryptographic key, acting as the destination for transactions. Similar to an IBAN in traditional banking, it allows users to receive digital assets. An address is typically a shortened hexadecimal string, generated by applying a hashing function to a public key. It functions as the public-facing identity of an account, ensuring that funds sent to it are only accessible to the entity possessing the corresponding private key.

## Definition

In blockchain, an address is a unique identifier derived from a public cryptographic key, acting as the destination for transactions. Similar to an IBAN in traditional banking, it allows users to receive digital assets. An address is typically a shortened hexadecimal string, generated by applying a hashing function to a public key. It functions as the public-facing identity of an account, ensuring that funds sent to it are only accessible to the entity possessing the corresponding private key.

## Simple explanation

An address is like your email address or home mailbox. You give it to people so they can send you coins, and because it is public, anyone can send money to it, but only you can access the coins inside because you hold the matching 'secret' key.

## Why it matters

Addresses are the fundamental way value is transferred across a network. Without a standard address format, it would be impossible to route assets securely between participants in a global, permissionless system.

## How it works

A user generates a private key, which is used to create a public key. Through a hashing algorithm (like Keccak-256 in Ethereum), this public key is transformed into a specific sequence of characters that serves as the public address. This process ensures the address is public, while the underlying private key remains mathematically linked but cryptographically obscured.

## Real-world example

A Bitcoin address starting with 'bc1' or an Ethereum address starting with '0x'.

## Advantages

- Allows permissionless asset reception
- Publicly verifiable ownership
- Cryptographically secure and unique

## Limitations

- Highly prone to user input errors
- Addresses are not human-readable by default
- Irreversible if funds are sent to the wrong address

## Common misconceptions

- Users often confuse the public address with the private key used to sign transactions.
- Some believe that an address represents a physical folder where coins are 'stored' inside the blockchain.
