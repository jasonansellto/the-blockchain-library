# Cryptography

Cryptography is the science of secure communication and data protection using mathematical techniques. In blockchain, it provides the backbone for verifying transactions, controlling asset access, and ensuring the immutability of the ledger. By using public and private key pairs, hashing functions, and digital signatures, cryptography prevents unauthorized access and tampering. It transforms human-readable data into a secure, encrypted format that only authorized parties can manipulate or verify.

## Definition

Cryptography is the science of secure communication and data protection using mathematical techniques. In blockchain, it provides the backbone for verifying transactions, controlling asset access, and ensuring the immutability of the ledger. By using public and private key pairs, hashing functions, and digital signatures, cryptography prevents unauthorized access and tampering. It transforms human-readable data into a secure, encrypted format that only authorized parties can manipulate or verify.

## Simple explanation

Cryptography is like a digital super-lock. It uses complex math to make sure that only you can spend your money and that nobody else can change the messages you send on the network.

## Why it matters

Without cryptography, blockchain would be insecure and easily hacked. It ensures ownership rights are protected and that the history of transactions cannot be rewritten.

## How it works

Users generate key pairs where the public key serves as an address and the private key acts as a digital signature. Hashing functions then link blocks together by turning data into a unique string of characters. This creates an unalterable chain that identifies any change in data immediately.

## Real-world example

The SHA-256 algorithm is used in Bitcoin to secure block headers and ensure the integrity of the transaction history.

## Advantages

- Ensures data integrity and authenticity
- Protects user privacy and ownership
- Enables secure peer-to-peer trust

## Limitations

- User error can lead to permanent fund loss
- Quantum computing poses a potential future threat
- High technical barrier for standard users

## Common misconceptions

- Cryptography is not just about hiding messages, but also about proving identity. People often mistake it for being only related to secret agent movies rather than everyday internet security.
