# Hashgraph

Hashgraph is a proprietary distributed ledger technology (DLT) that utilizes a directed acyclic graph (DAG) structure to record transaction history instead of a traditional linear blockchain. It employs a 'gossip about gossip' mechanism, where metadata about the communication history is included in every message. This allows the network to reach consensus on the order and timing of transactions without the energy-intensive mining process or the bottlenecks of block production, resulting in high throughput, near-instant finality, and fair ordering of events.

## Definition

Hashgraph is a proprietary distributed ledger technology (DLT) that utilizes a directed acyclic graph (DAG) structure to record transaction history instead of a traditional linear blockchain. It employs a 'gossip about gossip' mechanism, where metadata about the communication history is included in every message. This allows the network to reach consensus on the order and timing of transactions without the energy-intensive mining process or the bottlenecks of block production, resulting in high throughput, near-instant finality, and fair ordering of events.

## Simple explanation

Hashgraph is like a more organized way of keeping records. Instead of stacking pages one by one into a chain, it builds a complex web of events. Because every event includes information about the previous one, the computers can instantly agree on the exact order of every action taken, making it much faster than typical blockchains.

## Why it matters

Hashgraph offers an alternative model that solves the 'blockchain trilemma' by delivering high speed and security without the heavy environmental or hardware costs of mining. It is increasingly utilized for enterprise applications requiring high-frequency data processing.

## How it works

Nodes share transaction data and gossip-about-gossip events with peers. By analyzing this graph of events, every node can independently calculate the consensus timestamp for every transaction using a virtual voting algorithm. This deterministic process ensures total agreement on the order of transactions without needing to communicate further.

## Real-world example

Hedera Hashgraph is the primary public network that leverages the Hashgraph consensus algorithm to provide enterprise-grade performance for decentralized applications.

## Advantages

- Extremely high transaction throughput
- Near-instant transaction finality
- Energy-efficient consensus mechanism

## Limitations

- Uses a proprietary, patented algorithm
- Often perceived as more centralized than Bitcoin
- Complexity in auditing the DAG structure

## Common misconceptions

- Many people mistakenly label Hashgraph as a type of blockchain, though it is technically a directed acyclic graph.
- It is often assumed to be fully open-source, but the core consensus algorithm is currently patent-protected.
