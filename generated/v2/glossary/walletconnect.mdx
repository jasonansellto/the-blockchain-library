# WalletConnect

WalletConnect is an open-source protocol that facilitates a secure, encrypted connection between decentralized applications (dApps) and various non-custodial crypto wallets. By using a bridge server to relay messages between the user's interface and the blockchain, it allows users to interact with smart contracts without exposing their private keys to the dApp itself, preserving security while maintaining the convenience of mobile or desktop-based interaction.

## Definition

WalletConnect is an open-source protocol that facilitates a secure, encrypted connection between decentralized applications (dApps) and various non-custodial crypto wallets. By using a bridge server to relay messages between the user's interface and the blockchain, it allows users to interact with smart contracts without exposing their private keys to the dApp itself, preserving security while maintaining the convenience of mobile or desktop-based interaction.

## Simple explanation

Imagine you want to use a vending machine but don't want to hand over your wallet. WalletConnect acts like a secure remote control that lets the vending machine ask your wallet for payment, and you just press 'approve' on your phone.

## Why it matters

WalletConnect acts as the bridge that makes the Web3 ecosystem usable by connecting wallets to countless dApps. It is essential for interoperability and enabling users to participate in DeFi and NFT markets easily.

## How it works

The user initiates a session by scanning a QR code or clicking a deep link provided by the dApp. The WalletConnect protocol establishes an encrypted peer-to-peer bridge through a relay server. All transaction requests are routed through this tunnel for the user to approve on their mobile device.

## Real-world example

Connecting a MetaMask mobile wallet to Uniswap or OpenSea by scanning a QR code on a desktop browser.

## Advantages

- Secure interaction without key exposure
- Supports thousands of dApps
- Mobile-first seamless integration

## Limitations

- Depends on relay server uptime
- Potential for phishing if user ignores warnings
- Requires active internet connectivity

## Common misconceptions

- Many believe WalletConnect shares their private keys with websites, but it never does.
- Users often think it is a standalone wallet app, but it is actually a protocol for connecting existing wallets.
