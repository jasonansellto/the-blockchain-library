# Metadata

Metadata in the context of NFTs refers to the descriptive data that defines the characteristics, traits, and visual identity of a token. This data is usually stored in a JSON file format and links the blockchain token ID to external assets such as image files, animations, or audio. The metadata dictates the unique attributes of the NFT, such as 'color', 'background', or 'power level', which determine its rarity within a collection and how it is rendered in applications or galleries.

## Definition

Metadata in the context of NFTs refers to the descriptive data that defines the characteristics, traits, and visual identity of a token. This data is usually stored in a JSON file format and links the blockchain token ID to external assets such as image files, animations, or audio. The metadata dictates the unique attributes of the NFT, such as 'color', 'background', or 'power level', which determine its rarity within a collection and how it is rendered in applications or galleries.

## Simple explanation

Metadata is like the ID card for an NFT. It tells the computer everything it needs to know about the digital item, such as what it looks like, its name, and its special traits. Without metadata, a blockchain token would just be a generic code with no picture or identity attached to it.

## Why it matters

Metadata bridges the gap between raw blockchain data and user-friendly visual interfaces. It is essential for ensuring that an NFT's appearance and traits are standardized and recognizable across the internet.

## How it works

When an NFT is minted, the smart contract includes a URI (Uniform Resource Identifier) pointing to a metadata file, typically stored on decentralized storage like IPFS. This JSON file contains key-value pairs defining specific attributes. Wallets and marketplaces read this file to display the image and traits to the user.

## Real-world example

A CryptoPunk NFT's metadata contains information like 'Type: Alien', 'Accessory: Pipe', and 'Accessory: Small Shades', which defines its unique, rare visual appearance.

## Advantages

- Standardizes asset data across platforms
- Enables programmatic rarity calculations
- Allows for dynamic content updates

## Limitations

- Metadata can be lost if hosting servers fail
- Vulnerable to centralization if metadata URI points to private servers

## Common misconceptions

- Users often assume the image itself is stored on the blockchain, but it is usually only a link to the file.
- People believe metadata cannot be changed, though some dynamic NFTs allow for mutable metadata.
