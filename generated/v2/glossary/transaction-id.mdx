# Transaction ID

A Transaction ID (TXID), also known as a transaction hash, is a unique string of alphanumeric characters generated by applying a cryptographic hash function to the data of a specific transaction. It serves as a permanent, immutable digital fingerprint used to identify, track, and locate a transaction within a blockchain ledger. Once a transaction is broadcasted and confirmed, its TXID acts as the definitive proof of the transaction's existence and specific details, such as the sender, receiver, amount, and timestamp.

## Definition

A Transaction ID (TXID), also known as a transaction hash, is a unique string of alphanumeric characters generated by applying a cryptographic hash function to the data of a specific transaction. It serves as a permanent, immutable digital fingerprint used to identify, track, and locate a transaction within a blockchain ledger. Once a transaction is broadcasted and confirmed, its TXID acts as the definitive proof of the transaction's existence and specific details, such as the sender, receiver, amount, and timestamp.

## Simple explanation

A Transaction ID is like the tracking number for a package you ordered. If you want to see where your money went or confirm it arrived, you plug that unique ID into a search engine—called a block explorer—and it shows you exactly what happened with that specific transfer.

## Why it matters

Without a Transaction ID, it would be impossible to reliably track or verify the status of individual asset transfers within a decentralized network. It provides the transparency required for users and services to audit the movement of funds without needing to trust a central authority.

## How it works

When a transaction is created, the raw data, including input addresses, output addresses, and values, is passed through a hashing algorithm, such as SHA-256. This calculation produces a unique, fixed-length string. Even a tiny change in the transaction data will result in a completely different TXID, ensuring that the hash is intrinsically tied to the specific transaction content.

## Real-world example

When sending funds from a wallet like MetaMask or Coinbase, the platform provides a hash that you can paste into a block explorer like Etherscan to view your confirmation status.

## Advantages

- Enables transparent tracking of all funds
- Ensures cryptographic integrity of transaction data
- Allows for easy auditability of the ledger

## Limitations

- IDs are complex strings that are difficult to memorize
- Potential for malleability issues in certain protocols
- Cannot be changed once the transaction is broadcast

## Common misconceptions

- People often think a TXID is a private key, but it is actually public information that can be shared with anyone.
- It is a common myth that a TXID can be used to reverse a transaction; it is only a reference number and does not grant control over the funds.
