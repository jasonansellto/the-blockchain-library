# Threshold Signature

A signature scheme where a minimum number of participants must cooperate to produce a valid signature.

## Definition

A signature scheme where a minimum number of participants must cooperate to produce a valid signature.

## Why it matters

Cryptography provides the mathematical foundation for keys, signatures, privacy, integrity, and verification.

## How it works

The private key is split into multiple shards among participants using secret sharing. To sign a transaction, the required number of participants produce partial signatures using their individual shards. These partial signatures are combined to form a final valid signature that matches a single public key.

## Real-world example

Threshold signatures used in MPC-based custody solutions like Copper or Fireblocks.

## Advantages

- Enhanced security against theft
- Single signature efficiency
- Flexible governance models

## Limitations

- High network latency
- Complex setup process
- Requires online availability

## Common misconceptions

- Many assume it is just a synonym for multisig, but they differ in how they interact with the blockchain.
- Some think it requires every participant to be present, though it only requires a defined quorum.
