# Public Ledger

A public ledger is a decentralized, distributed digital database that maintains an immutable, chronological record of all transactions within a network. Unlike centralized databases controlled by a single entity, a public ledger is accessible and verifiable by any participant. It uses cryptographic proofs to ensure data integrity, meaning that once a transaction is confirmed and added to the ledger, it cannot be retroactively altered or deleted without consensus from the network participants.

## Definition

A public ledger is a decentralized, distributed digital database that maintains an immutable, chronological record of all transactions within a network. Unlike centralized databases controlled by a single entity, a public ledger is accessible and verifiable by any participant. It uses cryptographic proofs to ensure data integrity, meaning that once a transaction is confirmed and added to the ledger, it cannot be retroactively altered or deleted without consensus from the network participants.

## Simple explanation

Imagine a giant notebook that everyone in a class can see and write in, but no one can use an eraser on. Whenever someone sends money or data, everyone writes it down in their own copy of the notebook. Because everyone has a copy, if one person tries to cheat and change a number, the others will see it doesn't match their books and will reject the fake entry.

## Why it matters

Public ledgers eliminate the need for central intermediaries like banks to verify trust, as the network itself acts as the source of truth. This provides unprecedented transparency, auditability, and security for digital asset ownership and peer-to-peer economic activity.

## How it works

Participants on the network broadcast transactions, which are collected into blocks by validators or miners. These blocks are cryptographically linked to previous entries using hash functions, forming a chain. Once the network reaches consensus on the validity of a block, it is permanently appended to the ledger and synchronized across all distributed nodes.

## Real-world example

The Bitcoin blockchain serves as the archetypal public ledger, where every transaction from the genesis block to the most recent one is publicly searchable and verifiable via block explorers.

## Advantages

- Eliminates central points of failure
- Ensures complete transaction transparency
- Provides immutable historical records
- Enables trustless verification of data

## Limitations

- Potential for network scalability issues
- Publicly viewable sensitive transaction metadata
- High energy consumption for proof-of-work
- Difficult to correct erroneous transactions

## Common misconceptions

- It is often mistaken for a private corporate database that can be edited by admins.
- People wrongly assume that public transparency means all participants are anonymous or identifiable.
