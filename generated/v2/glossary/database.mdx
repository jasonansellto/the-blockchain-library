# Database

A database is a structured collection of data held in a computer, typically managed by a Database Management System (DBMS). Traditional databases are centralized, relying on a client-server architecture where a single administrator controls access, updates, and integrity. In contrast, blockchain-based databases represent a distributed ledger technology (DLT) where the state is replicated across multiple nodes. While traditional databases optimize for speed and CRUD operations, blockchain databases prioritize consensus, redundancy, and immutability over raw performance and data deletion.

## Definition

A database is a structured collection of data held in a computer, typically managed by a Database Management System (DBMS). Traditional databases are centralized, relying on a client-server architecture where a single administrator controls access, updates, and integrity. In contrast, blockchain-based databases represent a distributed ledger technology (DLT) where the state is replicated across multiple nodes. While traditional databases optimize for speed and CRUD operations, blockchain databases prioritize consensus, redundancy, and immutability over raw performance and data deletion.

## Simple explanation

Think of a traditional database as a single notebook kept by a librarian who decides who can see or change the records inside. A blockchain database, however, is like having thousands of copies of that notebook distributed to everyone in the world. When a change happens, everyone updates their copy at the same time, making it impossible to cheat or lose the information.

## Why it matters

This distinction matters because it shifts the trust model from human administrators to cryptographic protocols. It allows for permanent, tamper-evident record-keeping that is essential for trustless financial and supply chain applications.

## How it works

Traditional databases use SQL or NoSQL to organize data in rows, columns, or documents on centralized servers. Blockchain databases append data in chronologically ordered blocks, linked via cryptographic hashes to form a chain. Instead of centralized CRUD operations, data is verified via network consensus and written into the distributed ledger permanently.

## Real-world example

PostgreSQL is a standard centralized database, whereas the Ethereum ledger functions as a decentralized, global database for smart contract states.

## Advantages

- Data redundancy across nodes
- Tamper-evident historical records
- Trustless verification of state

## Limitations

- Slower read and write speeds
- High storage requirements
- Inability to delete data

## Common misconceptions

- People mistakenly think all blockchains are databases; a blockchain is a specific type of immutable, distributed database.
- Users often assume blockchain databases are always more efficient than traditional ones.
