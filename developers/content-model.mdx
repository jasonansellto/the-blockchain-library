## Content types

| Type | Purpose |
| --- | --- |
| Foundation | Explain a concept clearly |
| Tutorial | Help a user complete a task |
| Reference | Provide precise lookup information |
| Glossary | Define a term concisely |
| Architecture | Explain system relationships |
| Research | Preserve deeper analysis and publications |
| Changelog | Record meaningful project changes |

## Writing standard

Each page should answer one primary user intent, use descriptive headings, link to prerequisites, and distinguish facts from interpretation where relevant.
