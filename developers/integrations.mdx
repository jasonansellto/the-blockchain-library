## Current integration areas

The public project architecture is designed to support:

- Website publishing.
- GitHub collaboration.
- Mintlify documentation.
- ChatGPT App documentation.
- MCP-based integrations.
- Future API access.

## Integration principle

External interfaces should expose only the minimum data and permissions required for their documented purpose. Inputs, outputs, retention expectations, and limitations should be clearly described.
