## What this project is building

The project brings together educational material, developer documentation, AI-assisted learning, structured reference content, and open-source contribution workflows in one public knowledge system.

<Note>
The repository is designed to be a source of truth for documentation and educational material that can be published, indexed, reviewed, and reused across the wider Blockchain Library ecosystem.
</Note>

## Core areas

- **Learn:** beginner-to-advanced blockchain education.
- **Build:** technical resources for developers and integrators.
- **Explore:** glossary, research, publications, and reference material.
- **Connect:** AI interfaces such as the ChatGPT App and MCP Server.
- **Contribute:** community-driven improvements through GitHub.
