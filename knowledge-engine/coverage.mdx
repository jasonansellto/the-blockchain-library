# Coverage-driven content development

Version 1.3 adds a coverage engine that measures the resource depth of every canonical topic.

<Card title="Open the interactive coverage report" href="/reports/coverage/" icon="chart-no-axes-column-increasing">
See which topics are rich, developing, or still thin.
</Card>

## Coverage dimensions

A topic receives credit when it is connected to:

- Glossary definition
- Book
- Research
- Tutorial
- Code example
- AI prompt
- Quiz
- Learning path

The generated report lives at:

```text
/knowledge/coverage.json
```

This lets the editorial roadmap be based on actual gaps instead of intuition.
