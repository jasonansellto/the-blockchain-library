# Turning topic coverage into useful learning resources

Version 1.4 adds four resource types across ten high-value topics:

- Tutorials
- Code examples
- AI prompt patterns
- Knowledge checks

The initial enriched topics are Blockchain, Transactions, Wallets, Smart Contracts, DeFi, Layer 2, RPC Infrastructure, Interoperability, Deterministic Execution, and AI Agents.
