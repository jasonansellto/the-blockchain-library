## Canonical release (`/knowledge/`)

Compiled from the platform content on every sync. These are the files the website Explorer reads.

| File | Purpose |
| --- | --- |
| `knowledge-release.json` | Release contract: versions, build ID, totals, checksums |
| `catalog.json` | Flattened multi-object catalog |
| `graph.json` | Nodes and semantic edges |
| `related.json` | Related objects per UID |
| `search-index.json` | Searchable objects |
| `source-map.json` | Platform record ID → canonical UID |

## Curated knowledge (`/knowledge/curated/`)

Generated from the hand-maintained objects in `data/knowledge/`.

| File | Purpose |
| --- | --- |
| `index.json` | Version and collection counts |
| `coverage.json` | Topic coverage scores |
| `core/knowledge-graph.jsonld` | Linked-data metadata |
