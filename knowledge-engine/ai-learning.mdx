## One topic, many experiences

A single topic can connect to:

- its human-readable page
- glossary definitions
- books
- research
- AI prompt patterns
- quizzes
- developer documentation
- related topics

Prompt objects define reusable tasks. Quiz objects define assessment structure. Learning paths reference stable topic IDs and public routes.
