# Contributing

Thank you for helping improve The Blockchain Library.

1. Open or review an issue.
2. Create a focused branch.
3. Edit or add MDX content.
4. Add new pages to `docs.json` when they should appear in navigation.
5. Preview locally with Mintlify.
6. Open a pull request with a clear description.

Do not commit passwords, seed phrases, private keys, API keys, personal data, or other secrets.
