# Contributing

Thank you for helping improve The Blockchain Library.

## Ways to contribute

- Correct technical inaccuracies or outdated terminology.
- Improve clarity for beginners.
- Add practical examples or diagrams.
- Suggest new glossary definitions.
- Report broken links or accessibility issues.
- Improve documentation for the ChatGPT app or MCP server.

## Contribution standards

1. Use clear, plain language.
2. Distinguish facts from opinions.
3. Avoid promotional claims and price predictions.
4. Cite primary sources when introducing technical claims.
5. Do not include private keys, seed phrases, API keys, or personal data.
6. Keep educational material vendor-neutral unless a page is explicitly project-specific.

## Pull-request process

1. Create a focused branch.
2. Make one logical change per pull request.
3. Explain what changed and why.
4. Confirm that internal links work.
5. Confirm that pages remain readable on mobile devices.

## Content style

- Prefer short paragraphs and descriptive headings.
- Define acronyms on first use.
- Use examples without implying financial outcomes.
- Include risk and security context where relevant.
