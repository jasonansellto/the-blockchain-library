# v1.5.0 — Repository Professionalization

Version 1.5.0 formalizes the technical, editorial, and governance foundation of The Blockchain Library.

## Highlights

- project vision and long-term mission;
- architecture reference;
- formal knowledge data model;
- editorial standards;
- governance and contribution process;
- security policy;
- code of conduct;
- semantic changelog;
- project status;
- GitHub issue and pull-request templates.

## Why this release matters

The first four release lines established the Knowledge Engine, expanded the graph, added catalogs, enriched books and research, and added learning/developer resources.

Version 1.5.0 makes that platform maintainable for future contributors.

## Breaking changes

None intended.

## Migration notes

No knowledge-object migration is required.

Contributors should begin using the new governance, editorial, and pull-request guidance.

## Next

The next major platform direction is a versioned Knowledge API built over the existing canonical object model.
