## Purpose

The ChatGPT App extends The Blockchain Library into a conversational interface where users can ask questions and explore structured educational material.

## Intended uses

- Explain blockchain concepts.
- Help users navigate learning material.
- Surface relevant documentation.
- Support educational question-and-answer experiences.

<Info>This documentation describes the public integration model. Production capabilities should always match the currently deployed app and its published privacy disclosures.</Info>
