## Beginner prompts

- What is a blockchain?
- Explain wallets and seed phrases.
- What is the difference between a coin and a token?
- How do smart contracts work?

## Developer prompts

- Explain blockchain consensus trade-offs.
- Give me a learning plan for smart-contract development.
- Compare account-based and UTXO-style transaction models.
- Explain common wallet integration risks.
