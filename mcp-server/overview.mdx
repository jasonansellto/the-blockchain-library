## Purpose

The MCP Server is intended to expose approved Blockchain Library capabilities to compatible AI clients through structured tools and resources.

## Potential capability categories

- Knowledge search.
- Glossary lookup.
- Learning-path discovery.
- Documentation retrieval.
- Public project metadata.

<Note>The documented tool list should be kept synchronized with the deployed MCP server as implementation evolves.</Note>
