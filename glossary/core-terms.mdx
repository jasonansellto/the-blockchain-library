---
title: "Core blockchain terms"
description: "Concise definitions for foundational blockchain concepts."
---

## Address
A public identifier associated with a blockchain account or destination.

## Block
A structured collection of transactions or state transitions accepted into a blockchain's history.

## Consensus
The process or protocol through which network participants agree on valid state.

## Private key
Secret cryptographic material used to authorize signatures. It must remain private.

## Smart contract
Program logic deployed to a blockchain-compatible execution environment.

## Transaction
A signed request or recorded action that changes or references blockchain state.

## Wallet
Software or hardware that helps a user manage keys, addresses, and transaction signing.
