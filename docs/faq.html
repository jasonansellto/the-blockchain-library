Frequently asked questions

Is The Blockchain Library financial advice?

No. It provides educational information and technical explanations.

Do I need to own cryptocurrency to learn blockchain?

No. You can understand ledgers, consensus, wallets, smart contracts, and network architecture without buying digital assets.

Will the project ask for my seed phrase?

No legitimate educational tool needs your seed phrase. Never share it.

Is the project open source?

This public repository contains documentation, site pages, examples, and contribution materials. Additional components may be released over time.

What is the ChatGPT app for?

It is intended to make educational resources easier to explore through a conversational interface.

What is an MCP server?

An MCP server exposes structured tools and resources that compatible AI clients can discover and use.

Can educators contribute?

Yes. Educators can propose learning paths, corrections, examples, glossaries, assignments, and accessibility improvements.

How do I report a security issue?

Follow the private reporting instructions in SECURITY.md. Do not publish sensitive vulnerability details in a public issue.
