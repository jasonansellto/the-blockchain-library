Blockchain glossary

A growing reference for common blockchain and digital-asset terminology.

Blockchain

A shared digital ledger whose entries are grouped and linked according to a network's protocol.

Consensus

The process a distributed network uses to agree on valid state and transaction history.

Node

A computer that participates in a blockchain network by storing data, validating information, relaying messages, or producing blocks.

Wallet

Software or hardware used to manage keys, generate addresses, sign transactions, and interact with blockchain applications.

Private key

A secret cryptographic value used to authorize actions. Anyone who obtains it may be able to control the associated assets.

Seed phrase

A human-readable backup that can recreate a wallet's keys. It should never be shared or entered into untrusted software.

Smart contract

Code deployed to a blockchain that executes according to predefined rules.

Token

A digital unit created and managed by a blockchain protocol or smart contract.

Gas or transaction fee

The cost charged for processing an operation. Fee design differs by network.

Finality

The point at which a confirmed transaction is considered effectively irreversible under the network's rules.

Bridge

A system that moves or represents assets and messages between separate networks. Bridges introduce additional trust and security assumptions.

DeFi

Decentralized finance: financial applications built with blockchains and smart contracts.
