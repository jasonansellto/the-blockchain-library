# GitHub Pages site

This folder contains the static project and documentation site. Configure GitHub Pages to deploy from the `main` branch and `/docs` folder.

The HTML pages currently use canonical URLs on `theblockchainlibrary.com`. Update the canonical URLs and sitemap if the final published paths differ.

To use a custom subdomain such as `docs.theblockchainlibrary.com`, rename `CNAME.example` to `CNAME` and configure the DNS record.
