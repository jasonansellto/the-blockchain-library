Developer resources

The Blockchain Library is building a public technical foundation for educational tools, searchable reference content, and AI-connected learning experiences.

Repository resources

  • Public roadmap and changelog
  • Contribution and security guidelines
  • Static documentation pages
  • Planned MCP tool documentation
  • Planned examples for RPC, explorers, wallets, and smart contracts

Suggested first contributions

  • Improve a glossary definition.
  • Add a beginner-friendly diagram.
  • Report a broken or outdated link.
  • Propose an example using public blockchain data.
  • Improve accessibility or mobile layout.

Technical principles

Examples should be small, readable, and safe. They should use environment variables for credentials, validate external data, handle errors, and clearly distinguish test networks from production networks.
