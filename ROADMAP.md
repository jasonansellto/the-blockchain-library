# Roadmap

## Completed

### v2.0 — Knowledge Compiler & Reconciliation
Base44 export ingestion, canonical compilation, deduplication, provenance, graph/search generation and reconciliation.

### v2.1 — Knowledge Distribution
Versioned Knowledge Release, Mintlify distribution, public structured artifacts and safe Base44 return-sync contract.

### v2.2 — Knowledge Explorer
Public `/explore` with Discover, Search and Graph modes, build-ID caching, deep linking and related-resource discovery.

### v2.3 — Coverage Intelligence
Context-aware coverage scoring, priority analysis, centrality, matrix/category views, data-quality review, release snapshots, editorial tasks and exports.

## Current work — v2.3.1 Coverage Resolution & Diagnostics

- normalized Coverage Resolution objects;
- bidirectional edge resolution;
- category mapping;
- resource-type mapping;
- reference extraction;
- diagnostics and health checks;
- scoring-schema versioning;
- corrected baseline reset.

## v2.4 — Public Knowledge API

Planned read-only, versioned endpoints for status, search, topics, glossary, books, research, resources, code examples, learning paths, relationships and coverage. API responses must preserve canonical IDs and release provenance.

## v2.5 — AI and Learning Interfaces

Potential AI tutor, citation-aware answers, developer/research modes, adaptive learning and saved progress.

## v3.0 — Knowledge Platform Ecosystem

Potential public MCP server, developer SDKs, external integrations, richer graph queries, multilingual retrieval and ecosystem applications.
