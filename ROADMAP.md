# The Blockchain Library Roadmap

This roadmap tracks the public development of the repository, documentation, educational resources, AI integrations, and contributor experience. Priorities may change as the platform grows and community feedback is received.

## Phase 1 — Public foundation

- [x] Create the public repository structure
- [x] Publish README, license, security, and contribution policies
- [x] Launch an SEO-ready GitHub Pages starter
- [x] Add initial learning, glossary, developer, FAQ, roadmap, and changelog pages
- [x] Add branded repository artwork and project badges
- [x] Add expanded issue templates and community links
- [ ] Upload an official GitHub social preview image in repository settings
- [ ] Add final screenshots of the website and ChatGPT experience

## Phase 2 — Documentation expansion

- [ ] Complete the ChatGPT app overview and user guide
- [ ] Publish MCP server architecture and data-flow documentation
- [ ] Add a tool-by-tool reference for public capabilities
- [ ] Document installation, local development, testing, and deployment
- [ ] Add privacy, safety, limitations, and troubleshooting guidance
- [ ] Create reusable documentation templates for future project pages

## Phase 3 — Educational content system

- [ ] Expand the blockchain glossary into a structured reference library
- [ ] Publish beginner, intermediate, and developer learning paths
- [ ] Add knowledge checks, quizzes, and practical exercises
- [ ] Add downloadable educator and classroom resources
- [ ] Publish examples for wallets, RPC connections, smart contracts, explorers, and APIs
- [ ] Add content review dates and source-quality standards

## Phase 4 — Community and integrations

- [ ] Enable GitHub Discussions and configure topic categories
- [x] Create public bug, content, feature, and question workflows
- [ ] Publish integration examples for AI clients and educational platforms
- [ ] Add contributor recognition and acknowledgements
- [ ] Add automated link checking, HTML validation, and accessibility testing
- [ ] Add issue labels and a newcomer-friendly contribution queue

## Phase 5 — Platform maturity

- [ ] Introduce versioned documentation
- [ ] Publish a searchable API and tool reference
- [ ] Release structured datasets and public educational exports
- [ ] Add multilingual educational resources
- [ ] Add public release, service-health, and documentation-status dashboards
- [ ] Establish a recurring content audit and technical review process

## Long-term direction

The long-term goal is to connect an educational website, public documentation, AI-assisted learning, open-source examples, research, and books into a transparent blockchain knowledge ecosystem that can serve both people and software systems.
